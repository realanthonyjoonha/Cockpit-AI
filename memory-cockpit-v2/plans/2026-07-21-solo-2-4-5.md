   ```bash
   node scripts/propose-nbis.mjs --kind claim --text "…" --as-of 2026-07-20 --grade C --source slug
   node scripts/propose-nbis.mjs --kind risk_note --text "…"
   ```

   - No HTTP auth needed for local agents

3. Smoke: spawn propose CLI → list pending contains id → reject → gone from pending (or status rejected)
